# fpgaExperiments

Small FPGA experiments in Verilog, built and run on a Digilent Basys3 (Artix-7).

| Directory | What it does |
|---|---|
| [Gate-level greater-than circuit](Gate-level%20greater-than%20circuit/) | 2-bit and 4-bit greater-than comparators and a 2-bit equality comparator built from gates, with self-checking testbenches |
| [Gate-level binary decoder](Gate-level%20binary%20decoder/) | 2-to-4 decoder built from gates, with an `en` input that enables the outputs |
